Builder Training Document

H&S Builder Practice Pack

A realistic set of three health and safety templates designed to be rebuilt inside the form builder: Equipment Inspection, Job Hazard Analysis, and Near Miss Report.

Disclaimer Short Input Worker Choices Field Group Survey Knowledge Check Photo Phone Address Equipment Date / Time Number Basic Table Custom Table

Use This Pack

1. Rebuild the three sections in the same order.

2. Keep the labels exactly as written the first time through.

3. Add the conditional logic and calculations shown in the workflow notes.

4. After the first pass, compare your result against the matching JSON.

What this teaches

  • Sectioning a full document instead of a single flat form.
  • Mixing realistic field content with builder-only training notes.
  • Where to use conditionals, calculations, repeatable rows, and knowledge-check logic.

Workflows included

  • Conditional notes when a status is unsafe or treatment is required.
  • Calculated totals for repair cost and incident exposure.
  • Repeatable data using both Basic Table and Custom Table patterns.

Replication rule

  • Do not optimize on the first build. Replicate the structure first.
  • Use the chips beside each field to pick the matching builder component.
  • When fields are shown side by side, use a two-column example in the builder.
  • If a chip includes Conditional or Calculation, read the bottom notes on that page before configuring it.
  • Use the final crosswalk page if you lose track of a component.

Expected builder outcome

  • Three top-level sections: Equipment Inspection, Job Hazard Analysis, Near Miss Report.
  • At least three conditional fields, two calculated totals, one survey, one knowledge check, one photo upload, and both table types.
  • Multiple two-column rows that should be rebuilt with a column example, not as one long single-column stack.
  • A sample realistic enough to train users without looking like placeholder lorem ipsum.

Suggested build order

  • Create the three sections first.
  • Add the notices, then the main input fields, then the tables, then the workflow rules.
  • Whenever a row is shown side by side, rebuild it with a two-column example.
  • Save a draft before adding knowledge-check answer keys or calculations.
  • If a chip includes Conditional or Calculation, check the bottom notes on that page before finishing the field.
  • Compare against the matching JSON only after the first pass so the exercise still teaches layout decisions.
